The application sources were rearranged into folders for a Vitis project and the following Analog Devices files were modified for this board. Their copyright headers and licences are unchanged:

| File (in `vivado/ZC706/FMC_AD936X_PS/AD936X/`) | Change |
|---|---|
| `src/main.c` | TX and RX LO 70 MHz, baseband clock rates, transmit attenuation; prints 2048 captured I/Q samples of both receive channels on the serial console |
| `src/app_config.h` | selects the Xilinx platform and the DAC and ADC DMA examples; verbose messages off |
| `src/parameters.h` | whitespace only |
| `ad9361/ad9361_util.h` | driver messages (`printk`) printed on the console |
| `ad9361/ad9361_conv.c` | verbose output of the digital interface tuning |
| `iio/iio.c` | whitespace only |
| `iio/iio_app.c` | includes `app_config.h` |

In `vivado/ZC706/FMC_AD936X_PL/` the files are the same as in the Analog Devices `hdl_2021_r1` release. The prebuilt bitstream was built with bitstream compression enabled, which only reduces the file size.
